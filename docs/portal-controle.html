Sala Cara Core

Planos e campanhas Facebook, Instagram e LinkedIn. A Sala Cara Core é pública. Conteúdo em D:\dev\caracore-site\sala; oficina Python (D:\dev\caracore-mkt).

Acesso à sala

A Sala Cara Core é pública. O conteúdo (HTML, planilha, regis, prompts para IA, campanhas por rede) fica em sala/ no repositório do site (caracore-site/sala). Qualquer pessoa pode acessar index.htm, opera-sala, campanhas Facebook, Instagram, LinkedIn e a documentação.

Oficina em Python e esteira operacional

A oficina em Python (Baseline, Microsoft Store) está no projeto D:\dev\caracore-mkt: os 6 assistentes sincronizam, organizam e validam o trabalho do dia (iniciar trabalho, validar executado, transportar para face/gram/retro, validar entrega em cada sala). Eles retiram do jovem o peso das tarefas repetitivas; o fluxo é auditável. Os scripts atualizam a planilha (tarefa, horas, valor CC) e usam mensagens amigáveis para reportar via WhatsApp, Telegram ou e-mail. Sistema desenhado para privacidade (LGPD); uso fora das normas éticas bloqueia o acesso.
