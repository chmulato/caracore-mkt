Tecnologia - Cara Core MKT

Esteira de Organização de Trabalho: Python (Baseline) na oficina; HTML/CSS/JS na sala (pública). Auditável e desenhado para privacidade (LGPD). Não vendemos.

Oficina: Python (Baseline)

Os 6 assistentes da oficina (iniciar trabalho, validar, sincronizar/transportar, validar entrega face/gram/retro) são em Python. Usamos a versão Baseline instalada pela Microsoft Store, para comportamento igual em todos os ambientes. Projeto: D:\dev\caracore-mkt (pacote caracore_mkt e scripts/). Planilha em CSV; mensagens amigáveis para WhatsApp, Telegram e e-mail. O fluxo é auditável: cada etapa pode ser verificada.

Sala de Notícias: pública

A Sala de Notícias é pública. O conteúdo (planos, campanhas, prompts IA, feedback, planilha) fica em D:\dev\caracore-site\sala - HTML, CSS, JS estáticos. Estrutura assets/css, assets/img, assets/js. Qualquer pessoa pode acessar. Uso fora das normas éticas e de privacidade pode resultar em bloqueio de acesso.

Sala: HTML, CSS, JS

O conteúdo da Sala (planos, campanhas, prompts IA, feedback, planilha) é estático: HTML, CSS (assets/css), JS (assets/js) e imagens (assets/img). Páginas em sala/ (D:\dev\caracore-site\sala). Acesso público.

Privacidade e LGPD

O sistema foi desenhado para respeitar a privacidade (LGPD). Dados são tratados com finalidade clara; não há coleta desnecessária. O desenho auditável e a transparência são pilares: quem opera e a supervisão podem verificar os passos. Uso antiético bloqueia o acesso à sala.

Não vendemos

O Seed e o MKT são da Cara Core; não vendemos. Stack interna para uso da própria Cara Core (campanhas orgânicas, Sala de Notícias, oficina para quem opera).
