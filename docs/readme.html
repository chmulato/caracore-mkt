Documentação - Cara Core MKT

O que é o MKT, onde está a Sala Cara Core, oficina (Python), Portal (Node) e estrutura. Esta vitrine é gratuita para conhecer.

O que é o Cara Core MKT?

A Sala Cara Core é um ambiente de aprendizado e gestão operacional. Scripts de automação simples para um fluxo linear, organizado e justo. Centraliza a Sala Cara Core (planos e campanhas - pública), o Portal (acesso controlado) e a oficina (scripts em Python) que sincronizam, organizam e validam. O foco é a execução correta de processos; o sistema é auditável e desenhado para privacidade (LGPD). Uso fora das normas éticas bloqueia o acesso. Imagens e artefatos por e-mail a suporte@caracore.com.br. Ferramenta de uso interno - não comercializada.

Esta loja foi organizada para manter foco exclusivo no Cara Core MKT. O repositório de releases agora concentra apenas a vitrine, a documentação, o wiki e o artefato ZIP oficial do produto.

Vantagens

Não esquece de registrar

Você abre o computador, roda um comando e o sistema já anota que você começou a trabalhar. Como bater o ponto - mas automático. Sem planilha para abrir, sem campo para preencher.

iniciar_trabalho.py

Escreve timestamp ISO em planilha_sala.csv via csv.DictWriter com append controlado. Abre a sala no browser via webbrowser.open(). Zero intervenção manual.

Copia para o lugar certo

Você salva o post numa pasta. O software copia automaticamente para Facebook, Instagram e blog - sem arrastar arquivo, sem errar de pasta, sem esquecer uma rede.

transportar_para_salas.py

Itera ENTREGA_DIR com glob, copia via shutil.copy2 para FACE_DIR, GRAM_DIR e RETRO_DIR. Falha explícita com mensagem se destino não existir.

Avisa antes de quebrar

Se você salvou o arquivo com o nome errado, o sistema avisa antes de enviar. Como um corretor automático - mas para nomes de arquivo. Você corrige, aí manda.

validar.py - regex por canal

Aplica ^F_\d{4}-\d{2}-\d{2} (face), ^G_ (gram), ^article_ (retro). Retorna lista de erros para stdout. exit(1) em falha - integrável a CI.

Relatório de horas pronto

No fim do dia, o sistema imprime quanto você trabalhou e quanto ganha por isso. é só mostrar para quem paga - sem calcular nada na cabeça, sem contar horas no relógio.

validar_trabalho_executado.py

Calcula valor_sessao_cc = horas_trabalhadas - taxa_cc, acumula acumulado_cc, serializa em CSV e imprime mensagem formatada pronta para clipboard (WhatsApp/Telegram/e-mail).

Sem mensalidade, sem internet

Não tem assinatura, não tem cobrança mensal. Roda no seu computador e funciona offline. Não envia seus dados para nenhum servidor externo.

Zero dependências externas

requirements.txt usa apenas stdlib Python. Sem chamadas a APIs externas (sem OpenAI, sem Google, sem nada). Execução local com footprint de CPU e memória desprezível.

Limitações

Precisa instalar o Python

Você precisa ter o Python instalado no computador (disponível de graça na loja da Microsoft). Se nunca fez isso, leva uns 5 minutos com ajuda de alguém.

Sem binário standalone

Sem empacotamento em .exe. Dependência do py -3 no PATH. Não há instalador. Usuário precisa do Python Baseline (Microsoft Store) configurado corretamente.

Sem tela, só comandos

Você precisa digitar comandos no terminal (aquela tela escura). Parece intimidador, mas são sempre os mesmos 3 comandos. Com prática, vira rotina.

CLI puro, sem GUI

Sem interface gráfica ou TUI. Integração com IDEs via subprocess é possível, mas não há wrapper visual nativo. Onboarding de usuários não-técnicos exige treinamento inicial.

Histórico só no seu computador

O registro de horas e sessões fica salvo só na sua máquina. Se o computador pifar sem backup, o histórico se perde. Não tem nuvem automática.

Persistência CSV local

Sem backup automático, sem sincronia cloud, sem versionamento de dados. Adequado para uso individual. Não escalável para equipes distribuídas sem camada adicional (ex.: Git no CSV ou migração para SQLite).

Feito para a Cara Core

O software foi construído para a rotina da Cara Core. Usar em outro negócio com estrutura diferente (outras redes, outros nomes) exige ajuste com ajuda técnica.

Estrutura hardcoded

Caminhos configuráveis por env vars (CARACORE_REPO, CARACORE_SALA), mas a estrutura de pastas (face/, gram/, retro/) e os padrões de regex são hardcoded. Requer fork para adaptar a outro contexto.
